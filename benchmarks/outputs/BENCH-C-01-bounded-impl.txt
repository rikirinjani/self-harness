=== 1. CONSTRAINT RESTATEMENT (constraints.md) ===

- Implement a single function named `safe_divide(a, b)`.
- Inputs are numbers (int or float).
- Output is the quotient `a / b` when `b != 0`.
- If `b == 0`, return `None` instead of raising an exception.
- If either input is not a number, return `None`.
- No new dependencies.
- Must include a short docstring.

=== 2. IMPLEMENTATION ===

```python
def safe_divide(a, b):
    """Return a / b, or None for invalid inputs or division by zero."""
    if not isinstance(a, (int, float)) or not isinstance(b, (int, float)):
        return None
    if b == 0:
        return None
    return a / b
```
